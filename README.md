# CrowdLeague

**Find players. Find venues. Play more.**

CrowdLeague is a mobile app for finding and connecting with sports players at local venues. Built for the Melbourne basketball community, expanding nationally for Brisbane 2032.

## Features

- **Discover Venues** - Interactive map with photos and facility details
- **Build Your Crew** - Connect with players who share your interests
- **Coordinate Play** - Message your crew, get notified when friends are playing
- **Grassroots-First** - Designed for casual players, not elite athletes

## Tech Stack

- **Mobile App**: Flutter (iOS & Android)
- **Backend**: Firebase (Auth, Firestore, Storage, Functions, Messaging)
- **Maps**: Google Maps Platform

## Getting Started

```bash
# Install dependencies
flutter pub get

# Run the app
flutter run

# Run tests
flutter test
```

See [CLAUDE.md](CLAUDE.md) for detailed development documentation.
